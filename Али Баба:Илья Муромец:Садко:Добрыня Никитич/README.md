# Игры по мультсериалам

Каждая игра — это **один HTML-файл**. В нём уже всё: графика из мультфильма, уровни, озвучка рассказчика (русский и английский), звуки и музыка.
Интернет и сервер не нужны: файл можно открыть двойным щелчком, выложить на свой сайт или загрузить на игровую площадку.

## Что в архиве

- `index.html` — страница-витрина со всеми играми (для вашего сайта)
- `ilya-muromets.html` — «Илья Муромец и Соловей-разбойник», 7 уровней
- `dobrynya.html` — «Добрыня Никитич и Змей Горыныч», 8 уровней
- `sadko.html` — «Садко и Морской царь», 7 уровней
- `ali-baba.html` — «Али-Баба и сорок разбойников», 8 уровней
- `yandex/` — готовые архивы для Яндекс Игр (внутри `index.html` с подключённым SDK Яндекса):
- `yandex/ilya-muromets.zip`
- `yandex/dobrynya.zip`
- `yandex/sadko.zip`
- `yandex/ali-baba.zip`

## Где работает

Любой современный браузер: Android, iPhone/iPad, Windows, macOS, Linux.
Управление пальцем, мышью и клавиатурой (стрелки, пробел). Экран подстраивается под телефон и компьютер, есть кнопка полноэкранного режима.
Языки: русский и английский. Язык выбирается автоматически, его можно переключить кнопкой RU/EN.
Прогресс и звёзды сохраняются в браузере игрока.
Рассказчик читает сюжет, «Слово дня» и правила каждого уровня, а также итог и финал. Браузеры включают звук только после первого касания; текст можно переслушать, нажав на портрет героя.

## Как выложить на свой сайт

1. Загрузите папку целиком на хостинг (любой статический: свой сервер, Яндекс Облако, GitHub Pages, Netlify и т. п.).
2. Ссылка на игру: `https://ваш-сайт/папка/ali-baba.html`.
3. **Ссылка на конкретный уровень** (для конца ролика): добавьте `?level=N`, где N — номер серии.
   Например, после 3-й серии «Али-Бабы»: `https://ваш-сайт/папка/ali-baba.html?level=3`.
   Уровень по такой ссылке открывается сразу, даже если предыдущие не пройдены.
4. Язык можно задать в ссылке: `?level=3&lang=en`.

### Встроить игру в страницу

```html
<iframe src="ali-baba.html" style="width:100%;max-width:480px;aspect-ratio:9/16;border:0" allow="fullscreen; autoplay"></iframe>
```

### Кнопки «Смотреть мультфильм» и «Другие игры» в финале

Откройте HTML-файл в любом текстовом редакторе и найдите в начале строку:

```
window.FG_LINKS = { watch: "", site: "" };
```

Впишите ссылку на плейлист с мультфильмом (`watch`) и на ваш сайт (`site`). Пустые кнопки не показываются.

## Яндекс Игры

1. Откройте консоль разработчика Яндекс Игр и создайте черновик игры.
2. В разделе «Файлы игры» загрузите архив из папки `yandex/` (например, `yandex/ali-baba.zip`).
3. Игра уже подключает SDK (`/sdk.js`), сообщает о загрузке (LoadingAPI.ready) и о начале/конце игры (GameplayAPI), берёт язык игрока из Яндекса и выключает звук, когда вкладка скрыта.
4. Заполните описание, иконку и скриншоты (их можно снять прямо в игре) и отправьте на модерацию.

## Другие площадки

- **VK Play, CrazyGames, Poki, itch.io, GameDistribution** принимают HTML5-игры: загрузите HTML-файл (или ZIP, где он переименован в `index.html`).
- **Магазины приложений (Google Play, App Store, RuStore)**: HTML-файл можно обернуть в приложение (например, через Capacitor или PWABuilder) — сама игра менять не нужно.
- **Телефон как приложение**: откройте игру в браузере и выберите «Добавить на главный экран».
