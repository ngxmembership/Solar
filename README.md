# Солар — знания, которые светят

Кинематографичный сайт на скролле: Солар запечатан в звёздной скорлупе и постепенно раскрывается,
пока вы листаете страницу. Ролики для детей и взрослых, саммари книг о саморазвитии и браузерные игры.

**Сайт:** https://ngxmembership.github.io/Solar/

Публикуется автоматически: любое изменение в ветке `main` через 1–2 минуты появляется на сайте
(вкладка **Actions** показывает ход публикации).

---

## Как добавить игру

1. Откройте папку `public/games` в репозитории.
2. Нажмите **Add file → Upload files** и загрузите папку с игрой целиком
   (внутри должен быть файл `index.html`). Например: `public/games/zvezdnaya-matematika/index.html`.
3. Откройте файл `public/games/games.json`, нажмите карандаш ✏️ и добавьте запись об игре:

```json
[
  {
    "id": "zvezdnaya-matematika",
    "title": "Звёздная математика",
    "description": "Собирай созвездия, решая примеры на скорость.",
    "color": "#ff8f7a",
    "folder": "zvezdnaya-matematika"
  }
]
```

- `folder` — имя папки игры внутри `public/games`;
- `color` — цвет «планеты» игры (например `#8fe3c8`, `#ff8f7a`, `#8cc8f0`, `#c4a8f0`);
- несколько игр — несколько записей через запятую.

4. Нажмите **Commit changes**. Через пару минут игра появится в разделе «Игры» на сайте,
   а первые четыре игры станут планетами вокруг Солара.

Пока `games.json` пустой, на сайте показываются встроенные игры-заглушки и «Память Солара».

## Запуск на компьютере (для разработчика)

```bash
npm install
npm run dev
```

## Где что лежит

- `src/pages/solar/content.ts` — тексты, ролики, книги, ссылка на пожертвования (`DONATE_URL`);
- `src/pages/solar/scene/choreography.ts` — весь сценарий скролла: раскрытие, свет, камера, цвета неба;
- `src/pages/solar/stages/` — главы страницы;
- `public/games/` — ваши игры.
